# Autorização do Mercado Livre

Página de retorno (redirect) da autorização de um aplicativo no Mercado Livre. Depois que o vendedor clica em
«Permitir», o Mercado Livre abre esta página com o código de autorização no endereço, e a página só mostra esse
código para ser copiado. Ela não guarda, não registra e não envia nenhum dado: é um arquivo HTML estático, sem
scripts ou recursos de terceiros.
